## 1. 设计令牌

### 1.1 色彩

| 角色 | 令牌 | 色值 | 用途 |
|---|---|---|---|
| **主色** | `--bg-deep` | `#131C24` | 应用主背景（避开纯黑，降低压迫感） |
| | `--bg-panel` | `#18232C` | 卡片 / 侧栏 / 顶栏 |
| | `--bg-raise` | `#1E2A34` | hover / 输入区 / 选中态 |
| **文字** | `--ink-hi` | `#E4E1D6` | 正文 / 标题（月白，不用纯白减眩光） |
| | `--ink-mid` | `#B4BCC0` | 次级文本 |
| | `--ink-low` | `#8A959B` | 说明 / 占位符 |
| **辅助色** | `--jade` | `#5C8A99` | 石青：Agent 侧气泡、链接、激活态 |
| | `--jade-deep` | `#3A6474` | 深石青：分隔、节点 |
| | `--pine` | `#6E9276` | 石绿：成功 / 就绪状态 |
| **强调色** | `--gold` | `#B89A6B` | 赭石金：卷轴木轴、主 CTA、焦点环 |
| | `--gold-hi` | `#CBAE80` | hover 提亮、markdown 标题 |
| **点缀色** | `--seal` | `#C0695A` | 朱砂：钤印 / 删除 / 错误（**≤2% 面积**） |

**用法纪律**：主色铺满 100% 视口，是唯一的"地"；辅助色只出现在 Agent 侧与状态指示，不做大面积填充；强调色约占 5%（木轴 / 主按钮 / 焦点环 / 激活下划线）；朱砂一旦滥用会立刻破坏墨色主调。

## 3. 背景层：透明度预算（关键约束）

```
.ink-photo  AI 底图   opacity: var(--ink-photo-op, 0.16)
.ink-veil   二次压制渐变（上淡下浓）
```

| 位置 | 遮罩 alpha | 有效不透明度 |
|---|---|---|
| 顶部 0% | 0.28 | 0.16 × 0.72 = **0.115** |
| 26% | 0.62 | 0.16 × 0.38 = **0.061** |
| 50%（消息区） | 0.88 | 0.16 × 0.12 = **0.019** |
| 72% | 0.96 | 0.16 × 0.04 = **0.006** |
| 底部 100% | 1.00 | **0.000** |

> 内容区实际背景 ≈ `#131C24 + 1.9% 图`，几乎等同纯色底。图只存在于余光里。

**可调**：`--ink-photo-op` 由顶栏「山水」滑杆实时驱动，范围 0–0.40，默认 0.16，写入 `localStorage.lj_ink_op`。登录页用 `.dense`（×1.38）。

**底图**：`frontend/public/bg/shanshui-mist.jpg`，1920×1280，**120 KB**（由 1.34 MB PNG 压缩，饱和 −28% / 亮度 +6% / 对比 −10%）。

## 7. WCAG 自检

底色 `#131C24`，实测对比度：

| 前景 | 色值 | 对比度 | 评级 |
|---|---|---|---|
| 正文 | `#E4E1D6` | **12.94 : 1** | AAA |
| 次级文本 | `#B4BCC0` | **8.77 : 1** | AAA |
| 说明 / 占位 | `#8A959B` | **5.52 : 1** | AA |
| 赭石金（CTA / 链接） | `#B89A6B` | **6.38 : 1** | AA |
| 朱砂（错误 / 删除） | `#C0695A` | **4.62 : 1** | AA |

全部达 AA 以上，正文与次级文本达 AAA。

**边界提示**：底图平均色为浅青灰 `(183,197,211)`，会**提亮**底色。滑杆调至上限 0.40 时，内容区有效不透明度约 0.048，正文对比度约 11.5:1，仍属 AAA —— 即整个可调区间内可读性都不会破线，这是"硬上限 0.40"的依据。

### 唯一中等风险项：会话卷册

原实现里 `messages` / `timeline` 是**单会话全局 state**，改成多会话需要：

1. 把消息状态下沉到 `sessions[]`，每个会话独立持有 `msgs` / `timeline`
2. SSE 回调里的 `patchLast` 必须绑定到**发起时的** `session.id`（用闭包捕获 `sid`，不能读当前 activeId，否则切换会话会写串）
3. 流式生成期间禁止切换 / 删除会话，避免状态撕裂
4. localStorage 持久化需 try/catch + 数量上限（已设 30 条），防止配额溢出

**已采取的处理**：闭包捕获 `sid`；`streaming` 时禁用切换与删除；持久化包 try/catch。

### 已知限制（非阻塞）

- **`backdrop-filter`**：Firefox 需 103+ 且默认开启，旧版无模糊但仍有半透明底，功能不受影响
- **性能**：`backdrop-filter + blur(80px)` 墨滴在低端集显上有成本。墨滴仅 2 个且 `will-change:transform` 走合成层；`prefers-reduced-motion` 下完全静止
- **未做浅色版**：A 为深色主题，截图分享 / 打印场景需另出浅色版
