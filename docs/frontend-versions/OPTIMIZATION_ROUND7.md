## 二、背景

**前端主题演进线**：ROUND5 落档的「青绿设色山水（浅黛版，冷月白底）」之后，前端又经历了两次未落档的重构——v8「水墨留白」（宣纸白 + SVG 山峦，因用户要求"前端暂不同步"未写入 ROUND6），以及本轮 v9「青绿长卷」。

**本轮需求来源**（用户明确要求）：
1. 彻底移除大面积米白背景，改用有层次质感的配色（水墨灰 / 青绿 / 宣纸色 + 深色描边）
2. 融入中国山水画意境：留白、远山、水墨晕染、卷轴 / 画卷展开
3. 对话界面（最高优先级）：消息气泡、输入框、会话列表、整体排版重构
4. 登录界面与整体主题统一
5. 按钮统一五态（默认 / 悬停 / 点击 / 禁用 / 焦点）
6. 统一栅格、间距与留白方案

**决策过程**：先输出 3 个差异方向（A 青绿长卷 / B 水墨留白 / C 暗墨金线，含配色、关键元素、ASCII 布局与优缺点）→ 用户要求先渲染真实效果 → 产出三方向并排预览页 → 选定 **A 青绿长卷**，并追加两条硬约束：**严控 AI 图透明度**、**使用者看得舒心放松**；随后要求 AI 图透明度做成**可滑动调节**并附**技术难度评估**。

## 三、本轮改动要点

### 3.1 主题与设计令牌（迭代优化）

- **背景**：v8 米白宣纸底层次不足、缺画卷实体感；用户要求去米白、加质感。
- **文件**：`frontend/src/styles.css`（760 → 791 行）
- **要点**：
  - 主色 `#14202B` → `#131C24`（深青，避开纯黑降压迫）；正文纯白 → 月白 `#E4E1D6`（减眩光）；赭石金降饱和 `#B89A6B`
  - 行高 1.9 → 2.0；消息间距 24 → 26px；消息区 `max-width` 880 → 760px（收窄增留白）
  - 圆角整体加大（气泡 15px / 卡片 22px）；动效"慢而微"：墨滴漂移 34–52s → 120/150s、幅度 ±3vw → ±1.2vw
  - 描边全部半透明化；新增 `prefers-reduced-motion` 完全静止
- **与前几轮关系**：**迭代优化**——ROUND5「青绿浅黛」→ v8「水墨留白」→ v9「青绿长卷」，同一条山水主题演进线的第 3 代；ROUND3 的 banner / 模态 / 按钮体系沿用并升级为五态。

### 3.2 AI 山水底图 + 透明度预算（新增）

- **背景**：v8 用纯 SVG 山峦零请求但"假"；用户允许 AI 绘画并要求真实、且严控透明度。
- **文件**：`frontend/public/bg/shanshui-mist.jpg`（120 KB，1920×1280）、`frontend/src/InkBackground.jsx`（73 → 44 行）
- **要点**：
  - AI 生成柔和雾化青绿长卷 → PIL 压缩（1.34 MB → 120 KB）+ 调色（饱和 −28% / 亮度 +6% / 对比 −10%）
  - 分层透明度预算：`.ink-photo` opacity 0.16（硬上限）→ `.ink-veil` 二次压制（0%→0.28 / 26%→0.62 / 50%→0.88 / 72%→0.96 / 100%→1.00）
  - 内容区实际背景 ≈ `#131C24 + 1.9% 图`，几乎等同纯色底，图只存在于余光里
- **与前几轮关系**：**新增**——v8 的 SVG 山峦层被 AI 位图替代；背景层结构（墨滴 / 纹理）沿用 v8 思路并减负（3 墨滴 → 2）。

### 3.3 会话卷册与多会话（新增）

- **背景**：原实现 `messages` / `timeline` 是单会话全局 state，界面无会话列表；用户明确要求会话列表重构。
- **文件**：`frontend/src/App.jsx`（259 → 330 行）
- **要点**：
  - 新增左侧会话卷册（216px）：标题 + 时间 + 条数 + 悬停删除，选中项金线左缘
  - 消息状态下沉到 `sessions[]`，每会话独立持有 `msgs` / `timeline`，localStorage 持久化（上限 30 条）
  - 新会话标题取首条用户消息前 18 字
- **与前几轮关系**：**新增**——原为顶栏"新会话"按钮 + 单会话；本轮是首次引入会话列表。

### 3.4 消息气泡与角色印记（迭代优化）

- **背景**：v8 用户 / Agent 仅靠左右对齐区分，层级弱；要求明确信息层级与阅读节奏。
- **文件**：`App.jsx`、`styles.css`
- **要点**：用户右对齐（赭金描边 + 9% 底，右上收角），Agent 左对齐（石青描边 + 7% 底，左上收角）；新增 26px 楷体角色印记——用户「言」（金）、Agent「匠」（青），不单靠颜色编码。
- **与前几轮关系**：**迭代优化**——ROUND5 的"印泥红块面 / 竹青竖线"气泡升级为双描边 + 角色印记。

### 3.5 登录页三分构图（迭代优化）

- **背景**：v8 登录页居中卡 + 墨晕背景，与主界面构图分离；要求与整体主题统一。
- **文件**：`frontend/src/components/AuthPage.jsx`（49 → 74 行）
- **要点**：左=竖排题款「论匠」（`writing-mode:vertical-rl`）+ 钤印（纯留白定调）；中=1px 赭金中缝；右=372px 玻璃表单卡（blur 22px），为全页唯一行动区；背景用 `.dense`（×1.38）。
- **与前几轮关系**：**迭代优化**——v8 居中卡改为三分构图；ROUND5 的品牌印章 / 楷体语言沿用。

### 3.6 山水浓度滑杆（新增）

- **背景**：用户要求 AI 图透明度可滑动调节，自行决定数值。
- **文件**：`App.jsx`、`styles.css`（新增 `.ink-tuner`）
- **要点**：顶栏「山水」滑杆，0–0.40 实时驱动 `--ink-photo-op`，写入 `localStorage.lj_ink_op`；配套独立调参台 `design-concepts/tuner.html`（5 个滑杆 + 实时 WCAG 对比度计算 + CSS 导出）。
- **与前几轮关系**：**新增**——此前透明度为硬编码常量。

### 3.7 样式回归审计与修复（修复）

- **背景**：791 行 CSS 全量重写覆盖约 100 个类名，肉眼无法保证不漏；程序化审计发现 2 处遗漏。
- **文件**：`frontend/src/styles.css`
- **要点**：
  - 修复 `.kb-hits` / `.kb-docs` 丢失（v8 的 flex+gap 布局规则漏删 → 知识库列表失去纵向间距），容器统一 gap、子项 margin-bottom 归零防间距翻倍
  - 清理死样式：`.tl-tag.tool`（无 `tool` 事件类型）、`.auth-seal`（新版登录页不再渲染）
  - 审计方法沉淀为技能 `css-class-audit`：JSX 类名 ↔ CSS 选择器 ↔ git HEAD 三方比对
- **与前几轮关系**：**修复**——v8 既有样式在重写过程中被遗漏，属回归修复，非新功能。
