## 一、本轮改进总览

### 1.1 背景

v15 落地页引入「经典版式（#ln-site，light/dark）+ 编辑部版式（#ed-site，h/i/j/k）」双结构后，暴露出三类一致性缺口：

1. **编辑部版式无法切回**：唯一主题按钮 `#ln-theme` 位于 `#ln-site` 导航内，切进 h/i/j/k 后 `#ln-site` 被 `display:none`，页面上再无任何主题入口。
2. **两套版式导航 / 内容不对齐**：编辑部导航是「目次 / 工作台 / GitHub」，与经典版式四项不一致；编辑部版式缺「人机协同」「开始」区段与架构要目。
3. **吸顶导航遮锚点、顶栏盒位漂移**：两套版式 section 无 `scroll-margin-top`；顶栏控制区两套盒位不一致。

一致性修复完成后，落地页作为「展示门面」具备了稳定的交互基座，据此追加三门触发的彩蛋机关与三枚彩蛋页（纯前端、零新依赖、不进工作台主流程）。

### 1.2 涉及的前端模块或文件

- 落地页：`index.html`、`src/landing.css`、`src/landing.js`
- 彩蛋页：`public/easter/dispatch.html`、`public/easter/hunt.html`、`public/easter/brush.html`（新增）
- 清理：`design-samples/easter-game-{1,2,3}-*.html`（早期样张，已提升为正式页后删除）
- 工作台与后端：**零改动**（本轮不触及 `app.html` / `styles.css` / `useTheme.js`）

## 二、彩蛋机关设计（三门触发 · 状态机 · 三枚彩蛋页）

### 2.1 三门触发（`landing.js`）

| 门 | 触发条件 | 命中彩蛋 | 判定要点 |
|---|---|---|---|
| 手速门 | 5 秒内连点主题按钮 ≥6 下 | 彩蛋其一 · 编队调度局 | 命中后留 260ms 缓冲，把正在连点的最后几下也数进去；确认层文案报出实际手速（如「五秒内连点 8 下——手速这么快，别浪费，来当主控吧。」） |
| 精读门 | 划选正文 ≥10 字并保持约 0.9s | 彩蛋其二 · 查重捉虫 | 逐字读过才看得见风险；`selectionchange` 计时，弹层弹出期间不重复命中 |
| 书写门 | 在「落笔处」小砚纸（`.ink-pad`）写成一个字 | 彩蛋其三 · 临帖墨试 | 不认「写了什么」，只认「写成了一个字」：墨迹外接框两方向相对画布高度 32%/42% 撑开 + 至少两笔 + 总笔迹够长，故一、二、三这类单薄横画天然被排除 |

术语统一：三门并称「手速门 / 精读门 / 书写门」；三枚彩蛋编号固定为「彩蛋其一 · 编队调度局 → 彩蛋其二 · 查重捉虫 → 彩蛋其三 · 临帖墨试」。

### 2.2 确认层与状态机

- 命中后先弹俏皮话确认层 `.egg-veil`（「匠」印 + 一句调侃 + 「进去看看」/「先不急着进」），由玩家自行决定是否进入。
- 弹窗出现后，落笔处墨迹自动淡出；用户下一步**任意点击**（除「进去看看」按钮外，含点卡片、按 Esc）或 **10 秒无操作**均自动收层复位，**马上可以再次触发**（冷却仅 1.2~1.5 秒，只防同一手势连发）。
- 落笔处悬停自动进入宽容模式（提示与判定门槛同步放宽）；久未成字 20 秒自动清纸，乱涂乱画不会糊住入口。
- 解锁记录写入 `localStorage.lj_easter`，页脚（两套版式都有）显示「页边三则 · 手快者当主控 · 细读者见风险 · 落笔者得题款」与「（已解锁 x/3）」进度。

### 2.3 三枚彩蛋页（`public/easter/`）

| 页面 | 彩蛋 | 美术方向（同源主题） | 玩法概要 |
|---|---|---|---|
| `dispatch.html` | 其一 · 编队调度局 | 新构成主义（i：克莱因蓝 `#2B4BC7` / 红 `#D9402A` / 黄 `#DFA51E`，直角、2.5px 黑框、错位硬阴影） | 任务卡派给 6 位专项匠人，60 秒结算功名（童生 → 状元） |
| `hunt.html` | 其二 · 查重捉虫 | 墨格编辑部（h：纸白 `#FAF8F3` / 朱红 `#C8341F`，报头双线、双栏校样、红笔手绘圈） | 45 秒点掉风险标记（重 / 引 / 错 / 金），结算校对学徒 → 校对宗师 |
| `brush.html` | 其三 · 临帖墨试 | 秋香宣纸（g：宣纸 `#E6DECB` / 茶褐 `#A0824A`） | 按字帖运笔，实时算覆盖率 / 出墨率，收笔评定习作 → 神品，作品可下载保存 |

三页共有：零资产音效（Web Audio，可关）、`../index.html`（返回门面）与 `../app.html`（进入工作台）回链、页内标注「彩蛋 其X / 叁」。

## 三、验证结论

- 静态核对（本轮文档同步时复验）：`landing.js` `node --check` 语法通过；`#ed-theme` / `#ed-synergy` / `#ed-start` / `#ed-readout` / `#ed-toc` 锚点与导航 `href` 一一对应；两套版式各含一个 `.ln-theme-btn`；彩蛋页 `../index.html`、`../app.html` 回链目标均存在。
- 交互与视觉实测（代码提交方）：顶栏控制区对齐后，六主题下主题按钮盒横向一致，同坐标连点可稳定触发手速门（详见 [`CHANGELOG-v15.md`](./CHANGELOG-v15.md) §九-7）。
- 本轮为纯前端展示层改动，工作台与后端零回归；构建 / eslint 由前端提交链验证。

## 四、工程纪律

- 「追加式」：`landing.css` 的 `scroll-margin-top`（`:789`）与彩蛋 / 顶栏对齐段（`:1101` 起）均为追加，A–K 既有规则零修改。
- `landing.js` 彩蛋机关集中追加于文件末（`:90` 起），入口处加 `window.__ljLandingInit` 守卫，避免二次挂载时监听器叠加。
- 零新依赖、零图片资产：彩蛋页视觉全 CSS / Canvas，音效走 Web Audio 合成。

## 六、已知边界

1. 彩蛋机关为落地页专属交互，**不影响**工作台；三枚彩蛋页为独立静态页，不进 vite 构建入口。
2. 手速门依赖两套顶栏主题按钮盒位对齐（本轮已对齐）；若后续版式再调整顶栏，需复检该前置条件。
3. 书写门采用「像不像一个字」的宽容启发式（外接框 + 笔画数 + 笔迹长度），非真实 OCR，属有意设计。
4. `#ed-site` 与 `#ln-site` 文案仍为同源静态副本，新增区段亦需人工同步（CHANGELOG-v15 §九-5 的同步责任不变）。
5. `lj_landing_theme` / `lj_easter` 与工作台 `lj_theme` 相互独立（设计如此）。
