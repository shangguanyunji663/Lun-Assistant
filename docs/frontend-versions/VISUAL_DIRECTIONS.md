# 论匠前端 v8 · 视觉重构三方向提案

> 文档域：frontend-versions
> 文档类型：提案
> 主题版本：v8
> 轮次：—
> 日期：2026-09-01
> 状态：提案

> 起草于 v8「水墨留白」之后，针对"米白宣纸底层次不足 / 对话区信息层级弱 / 缺画卷实体感"三个痛点，给出 3 个差异明显的方向。  
> 三张 AI 山水底图位于 `design-concepts/`，仅作风格锚点；选定方向后会重新出图（去除"AI生成"水印）并铺到 `frontend/public/`。

## 现状速诊（v8）

| 模块 | 现状 | 问题 |
|---|---|---|
| 背景 | 宣纸白 `#F6F5F0` + SVG 山峦 + 径向墨晕 | 米黄偏暖、整体偏平、缺画卷实体 |
| 消息气泡 | 单色描边圆角矩形 | 用户 / Agent 区分度靠左右对齐，信息层级弱 |
| 输入区 | textarea + 圆角按钮 | 按钮"墨色"与"朱砂"对比不够；缺状态系统 |
| 侧栏 | 三 tab + 卡片 | tab 切换无视觉延续；时间线节点无色彩编码 |
| 登录页 | 居中卡 + 墨晕背景 | 与主界面共享色板但构图分离 |
| 控件 | `.btn / .btn-ink / .btn-ghost / .btn-danger` | 缺 disabled / loading / focus 统一规范 |

## 方向 A · 青绿长卷（卷轴展开）

**风格定位**：宋元青绿山水（王希孟《千里江山图》）+ 装裱卷轴的视觉语言。中明度、中彩度，"有山有水有色"，是 3 个方向中差异化最大、最"出片"的一个。

**配色**

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#14202B` 靛青底 | 100% 铺满 viewport（彻底替代米白） |
| 辅助 | `#2E6B7E` 石青 | 侧栏、册页卡底（rgba 0.65 + backdrop-blur） |
| 辅助 | `#4F7A5B` 石绿 | 次级强调（hover 描边、节点 success） |
| 强调 | `#C8A15A` 赭石金 | 卷轴木轴、焦点环、激活态下划线 |
| 点缀 | `#A83E32` 朱砂 | 仅钤印与删除按钮，控制在 2% 面积 |

**关键元素**
- 顶 / 底各一道赭石金木轴条（高 8px），强化"卷轴"语言
- 背景图 = AI 生成的青绿长卷：顶部 30vh 视差，opacity 0.35，叠加暗角
- 会话条目 = 册页式：左侧细墨线 + 编号 + 标题 + 末条消息时间戳
- 消息气泡 = 描边样式（1.5px `#3A4A55`），无填充；hover 时转 0.04 alpha 填充

**布局草图（chat 主界面）**
```

│  ╱ 论匠 ◉   〔 #1 项目A ▾〕  +新建  对话 可观测  退出   ╲         │
├──────────┬───────────────────────────────────┬─────────────────────┤
│ 会话卷册 │  〔 山 峦 远 影 背 景 〕           │  时间线 / 知识库    │
│ 240px    │                                   │  档案               │
│          │   user:  右对齐, 描边 + 浓墨字   │  320px              │
│ ◇ 新会话 │                                   │                     │
│ 昨 14:20 │   assistant:  左对齐, 描边 0.6   │  ● node_start 石青  │
│ 昨 11:05 │              引导文 + 印章徽    │  ● route      石绿  │
│ 更早 →   │                                   │  ● plan       赭金  │
│          │   〔 interrupt 反馈条 〕           │                     │
│          │   ┌── input bar ───────────────┐  │                     │
│          │   │ [textarea............] [发送] │                     │
│          │   └────────────────────────────┘  │                     │
└─[ 木轴 bot #C8A15A, 8px ]──────────────────────────────────────────┘
```

**优缺点**
- ✅ 层次感与"画卷展开"最直观；3 个方向中差异化最大
- ✅ 深色底对长文阅读友好（配合月白文字）
- ✅ 顶/底木轴 + 册页条目把"中国卷轴"做成可识别母题
- ⚠️ 深色底与传统宣纸白反差大，可能偏"游戏 UI"——需严格控 AI 图透明度
- ⚠️ 对配色一致性要求高（4 个色阶 + 2 个强调色），改造量中等
- ⚠️ 截图分享 / 打印场景需额外出"浅色版"

## 方向 B · 水墨留白（宣纸册页，改良版）

**风格定位**：倪瓒式疏淡 / 八大山人极简。**在 v8 基础上"提质感、不换底"**——彻底去米黄、引入冷灰白与一点石青，主打"典雅克制"的最稳妥路径。

**配色**

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#ECEAE3` 冷宣白 | 60% 应用底（替代 v8 的 `#F6F5F0` 米黄） |
| 辅助 | `#C4C5BD` 远山淡灰 | 30% 侧栏底 / 卡片分隔 / 分隔线 |
| 文字 | `#1C1C1A` 墨色 | 正文 / 标题（95% 对比度） |
| 强调 | `#3C6E8F` 石青 | 8% 链接 / hover / 激活态 |
| 点缀 | `#A83E32` 朱砂 | 2% 钤印 / 删除 / 危险 |

**关键元素**
- 背景图 = AI 生成的倪瓒式极简远山：右下 40% 区域，opacity 0.12，vignette 暗角，几乎"只在余光中"
- 顶栏品牌区 = 小楷"论匠" + 16px 细横线（BrushRule 已存在）
- 消息气泡 = 用户右对齐淡石青描边，Agent 左对齐深墨描边；两者均无填充，纯靠"线"区分
- 会话列表 = 4px 编号墨点 + 标题 + 末条预览 + 时间；hover 整行淡灰底

**布局草图**

```
│ 会话 4   │                                  │  时间线          │

│          │                                  │  档案            │
│ 淡灰底   │   user:  右对齐, 描边 #3C6E8F     │  320px           │
│ 1px 分隔 │                                  │                  │
│          │   assistant:  左对齐, 描边 墨色   │  ○ node_start    │
│ □ 新会话 │              印章 + 引导文       │  ○ route         │

│          │   ┌──── input bar ────────────┐   │    引导)         │
```

**优缺点**
- ✅ 与"宣纸 / 留白"传统意境最贴；改造风险最低（保留信息架构）
- ✅ 阅读体验最好；打印 / 截图 / 分享无障碍
- ✅ 3 个方向中工程量最小（≈ 2-3 天）
- ⚠️ 与 v8 差异最小，可能让人觉得"没换"
- ⚠️ 浅底层次感弱，需靠阴影、细线、印章补
- ⚠️ "AI 山水背景"在这种底上效果最弱（只能放角落低透明度）

## 方向 C · 暗墨金线（夜山金碧）

**风格定位**：李可染"积墨"夜山 + 金碧山水的现代转译。低明度、高质感，把"古典意境"做成"当代仪表盘"，是 3 个方向中最高级、最"沉浸"的一个。

**配色**

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#0E1012` 焦墨 | 100% 应用底（最暗） |
| 辅助 | `#16191C` 深墨 | 卡片 / 侧栏底（与主色仅 5% 亮度差，靠 1px 金线区分） |
| 辅助 | `#2F4756` 石青低饱 | 时间线节点 / 成功状态 |
| 文字 | `#E8E4D9` 月白 | 95% 对比度正文 |
| 强调 | `#C9A227` 赭金 | 1px 金线描边（hover/active/焦点） |
| 点缀 | `#B04A3A` 朱砂 | 1% 发送按钮 = 朱砂印章 |

**关键元素**
- 背景图 = AI 生成的月光夜山：全屏 bottom 60%，opacity 0.45，叠 deep overlay，顶部留出"夜空"为消息区
- 卡片 = 玻璃拟态：`rgba(22,25,28,0.72)` + `backdrop-filter: blur(20px)` + 1px 金线（仅 hover/active 出现）
- 消息气泡 = 玻璃面 + 月白文字；用户态右对齐 / Agent 态左对齐，hover 时金线亮起
- 时间线当前节点 = 赭金高亮 + 6px 金点
- 发送按钮 = 36×36 朱砂印章（不是按钮，是"盖章"）

```
│ 240px    │                                  │  知识库          │
│ 焦墨底   │  user:  玻璃面 rgba墨+blur       │  档案            │
│ 金线分隔 │           月白文字, 描边 0       │  320px           │
│          │                                  │  焦墨更深        │

```

**优缺点**
- ✅ 质感 / 高级感 / "沉浸"三料第一；AI 背景在暗底上最"真实"且不易脏
- ✅ 长时对话护眼；月白文字 + 赭金描边符合 WCAG AAA
- ✅ 朱砂印章"发送" = 母题最统一（钤印 = 提交）
- ⚠️ 暗色 UI 与"宣纸留白"意境有距离，可能让期待传统美学的用户觉得"不够东方"
- ⚠️ backdrop-blur 在低端机有性能成本（需提供降级）
- ⚠️ 截图分享 / 打印不友好；需额外出"浅色版"或自动翻转
- ⚠️ 改造工程量最大（≈ 4-5 天，所有描边 / 阴影 / 模糊都要重做）

## 三方向速览对比

| 维度 | A 青绿长卷 | B 水墨留白 | C 暗墨金线 |
|---|---|---|---|
| 主明度 | 中（靛青底） | 浅（冷宣白） | 暗（焦墨底） |
| 色彩饱和度 | 中高（青绿金） | 低（灰 + 一点青） | 低（金线 + 朱砂点） |
| 母题强度 | 卷轴（强） | 册页（中） | 金碧山水（强） |
| AI 图占比 | 大（30vh 顶） | 小（右下 40%） | 大（bottom 60%） |
| 信息层级清晰度 | ★★★★ | ★★★ | ★★★★★ |
| 阅读舒适度 | ★★★ | ★★★★★ | ★★★★ |
| 改造工程量 | 中 | 小 | 大 |
| 打印 / 截图友好 | 需浅色版 | 原生友好 | 需浅色版 |
| 与 v8 差异度 | 大 | 小 | 最大 |

## 选定方向后，我会一次性交付

1. **设计令牌（design tokens）**：颜色 / 字号 / 行高 / 间距 / 圆角 / 阴影 / 描边，共 6 类，全部走 CSS 变量
2. **AI 底图终稿**：按选定方向重新出图（去水印、烘焙暗角、压成合适透明度），放入 `frontend/public/`
3. **`InkBackground.jsx` 重写**：以新底图为背景层，叠加 1-2 层几何（卷轴木轴 / 细墨线 / 金线）
4. **`styles.css` 全量重写**：约 800 行；含按钮 4 态（default / hover / active / disabled / focus）规范
5. **`App.jsx` 改写**：消息气泡新结构（区分 user / agent）、输入区新结构、侧栏会话列表新结构、登录页新构图
6. **栅格与留白规范**：12 栅格，gutter 16px，外边距 24/32px，断点 768 / 1024 / 1440
7. **WCAG 自检报告**：所有文字-底色对给出对比度值

预计总代码量 ≈ 1000-1400 行（替换 v8 的 1700 行；其中 InkBackground + styles.css 占大头）。
