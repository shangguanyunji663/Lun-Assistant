**意图分类 4 条 miss（真实失效模式）**：

| 查询 | 期望 | 实得 | 所在层 | 原因判断 |
| :--- | :--- | :--- | :--- | :--- |
| 我对大模型感兴趣能研究点啥 | topic_analysis | literature_search | vector | 开放式提问被「文献」类原型抢走 |

> **口径说明（为什么不是 100%）**：09-04 快照记录的「50/50 = 100%，rule 16 / vector 34」是

> 本次重跑得到真实水位 92%。另需注意：L2 向量层的原型句与测试集存在同源改写
> （如「你能做什么」逐字相同、8 条字面 Jaccard ≥ 0.6），因此 92% 仍偏乐观，
> 更严格的结论需要独立 hold-out 意图集 —— 这一项尚未做。

### 5.2 改进效果（**2026-09-04 新增**）：主题词表机制落地

| 阶段          | 口语长尾集 Recall\@5 | 说明                       |

- 零配置改动：所有查询自动受益，无需改动管线接口或评测流程。

## 六、已知边界 / 未覆盖项

1. **CPU 底座性能基线**：bge-m3 嵌入 + bge-reranker CPU 推理，单查询 3–75s、压测 QPS 1.9；换 GPU / Redis 缓存嵌入后可显著提升（性能条目不参与"口径通过"判定）。
2. **Redis 无 RediSearch 模块**：`FT.INFO` 未知命令 → `TieredCheckpointer` 降级到进程内存（重启即丢），仅影响 interrupt 跨重启恢复；开发模式可用。
3. **harness「context 压缩」依赖 LLM**：未接 LLM 时该项会 SKIP（不影响其它项）。
4. 冒烟中 `ingest_corpus` 展示的是幂等跳过路径；全新环境首跑请在空库上验证。
