## 一、许可基线：传统纹样属公有领域

中国传统纹样（缠枝莲、卷草、云纹、回纹、宝相花、冰裂纹等）是**历经数千年、多代匠人集体打磨迭代形成的公共文化符号**，依据：

| 要件 | 传统纹样 | 结论 |
|---|---|---|
| 独创性智力成果 | 无明确、单一创作主体 | 不构成著作权法意义上的"作品" |
| 保护期限 | 诞生年代久远，远超「作者终生 + 50 年」 | 已过保护期 |
| 司法共识 | 原汁原味、未经改动的原生传统纹样属民族公共文化资源 | 任何人可合理使用，**不得独占、确权、垄断** |

**但机械照搬不产生著作权。** 法律界明确建议：可取用古代原始纹样原型，
但**须自主重构**——调整造型、数量、构图、线条、配色；**禁止直接复刻他人已优化的完整图案布局**。

因此本目录中所有文件均为**依据传统造型规律重新设计的原创几何**，不提取、不描摹任何具体文物图样。

### lotus-scroll.svg · 缠枝莲

依传统缠枝莲纹的三条造型规律重构：

1. **枝茎作「切圆式」转折** —— 主蔓走半圆弧，与分枝穿插形成切圆空间，花缠在弯道内；
2. **莲花突出中心莲蓬，花瓣取九片** —— 传统区间为 8–12 片（佛教象征的固定数）；
3. **叶片三歧分叉，尺寸约为花头径的三分之一** —— 以大小对比强化主次。

构图遵**「同花异向」**：相邻两朵莲花在藤蔓中呈相反朝向，使循环中保持变化。
这是元青花缠枝莲的典型处理，用于破除"机械平铺"的生成感。

花瓣旋转角刻意取 40.6° / 81.1° / 121.7°…（而非整除的 40°），
使九瓣不落在数学对称点上——手绘花瓣本就不完全等分。

### meander.svg · 雷纹

两处改动服从两条硬约束：

1. **断续不等长** —— 三段方折长短不一，非等距重复；
2. **大留白** —— 段间留 32–40px 空白，模拟「笔断意连」，不把纹样填满边缘。

## 三、用金法则（原「金碧辉煌」候选皮肤的设计依据 · 该皮肤已删除）

金碧山水的用金有明确禁忌。《绘宗十二忌》原文：

> 「金碧，则下笔之时其石便带皴法，当留白面，却以螺青合绿染之，后再加以石青绿，
> 逐折染之。……**金泥则当于石脚沙嘴霞彩用之。**」

即：**泥金只用于石脚、沙嘴、霞彩等局部点睛，不可当作描边系统铺满界面。**
又有「青绿为质，金碧为文」「阳面涂金，阴面加蓝」——金是"文"（装饰），
青绿是"质"（主体），主次不可颠倒。

设色工序（传统积旋法，逐层叠加而非一次成色）：
`淡赭打底 → 草绿分阴阳 → 重汁绿压棱角 → 石绿石青重点加染（上重下轻）→ 轻罩 → 泥金点睛`

当时的「金碧辉煌」候选皮肤依此把金色用量压到三处：品牌印边框、主行动按钮、关键数字。
（现行皮肤 G「编队总谱」是无彩钴蓝语言，**不适用**本条——记录在此仅为说明纹样取材与设色的自查方法。）
