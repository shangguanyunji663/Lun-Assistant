本文围绕检索增强生成（RAG）的评测鲁棒性展开。已有研究表明，向量检索与关键词召回的多路融合能够显著提升长尾查询的命中率，但在对抗查询与检索失败场景下，指标波动仍然明显。为刻画这一现象，本文构建了包含三类扰动的评测集：对抗查询、检索失败与引用幻觉。

在方法上，我们采用混合三引擎召回（稠密语义 / BM25 稀疏 / 句子窗口），经 RRF 融合后再由交叉编码器精排。实验显示，融合后再排序的策略在 20 条简单集上取得 Recall@5 = 100%，但在学术刁钻集上仍有提升空间。需要说明的是，本文所有实验均在本地推理底座上完成，不依赖外部服务。

关于局限：其一，口语化长尾查询的改写质量高度依赖改写模型，存在语义漂移的风险；其二，跨会话记忆依赖结构化档案而非聊天记录，长期一致性仍待验证。后续工作将围绕引用边界标注与重写策略的联合优化展开，并在更大规模的评测集上复现全部结论。

可复现性方面，全部实验脚本、评测集与复现命令随仓库分发；离线用例覆盖治理、模型、改写与 API 四个层面。我们认为，把水位如实标注比宣称满分更重要——50 条意图集的实测结果是 92%（4 条未命中，含 3 条开放式提问被误路由到闲聊），口语长尾集 80%、hold-out 泛化 75%；每个数字的口径与数据集指纹记于 evals/results_latest.json 的 _provenance 字段。
