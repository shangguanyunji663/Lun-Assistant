# 图神经网络（GNN）：从图表示、消息传递到知识图谱与图检索增强
# 收录于 计算机检索增强语料库
一、引言：为什么需要图神经网络
现实世界中的大量数据天然具有图结构：社交网络中的用户关系、分子结构中的原子连接、知识图谱中的实体与关系、电商网络中的商品与用户交互、交通路网中的站点连通，乃至代码的抽象语法树与程序数据流图。传统深度学习方法（如神经网络、卷积神经网络）假定数据分布在规则网格上，例如图像是规则的像素矩阵、文本是线性序列，它们难以自然地处理节点数量不定、连接关系各异、语义通过拓扑承载的图数据。图神经网络（Graph Neural Network，GNN）应运而生，它将深度学习引入图结构数据，通过迭代式的消息传递（Message Passing）机制聚合邻居信息，从而学习节点、边乃至整个图的嵌入表示。GNN 的核心假设是同质性（Homophily）与局部平滑性：相邻节点往往共享相似特征，聚合邻居信息能够丰富自身的表示。经过近十年的发展，GNN 已广泛应用于节点分类、链路预测、图分类、社区发现、分子性质预测、推荐系统、药物发现、流量预测与物理系统建模等领域。在检索增强生成（RAG）的多跳推理场景中，图神经网络正与知识图谱深度结合，用于结构化知识的表示学习与图检索，帮助大语言模型突破单一文档的局限、实现跨节点与跨关系的复杂推理。理解 GNN 需要把握三个层面：如何把数据表示为图、如何在图上做消息传递与表示学习、以及如何把图数据接入下游任务与检索系统。
二、图的表示与图嵌入基础
图（Graph）在数学上通常表示为 G = (V, E)，其中 V 是节点（或顶点）集合，E 是边（或连接）集合。图可以是无向图（边无方向）或有向图（边有方向），可以是无权图（边仅表示连接）或有权图（边上带权重），还可以区分节点属性（特征向量）与边属性，以及引入多重边、超边等更复杂的结构。在计算机中，图常用邻接矩阵（Adjacency Matrix）或邻接表（Adjacency List）存储，邻接矩阵 A ∈ R^{n×n} 中 A_ij 表示节点 i 与 j 是否相邻（或边权重），配合节点特征矩阵 X ∈ R^{n×d}（每个节点有 d 维特征，如文本表示、数值属性）。图本身是高度稀疏的结构，因此邻接表在实际工程中更节省内存。图嵌入（Graph Embedding）的目标是把图结构中的节点、边或整图映射为低维稠密向量，使得向量之间的相似度反映图结构上的相似性。早期的图嵌入方法如 DeepWalk 与 Node2Vec 借鉴了词向量 Word2Vec 的思想，通过在图上做随机游走生成节点序列，再用 Skip-gram 或 CBOW 学习节点表示；LINE 方法则显式建模一阶与二阶邻近度；SDNE 采用自编码器捕捉非线性结构。这类基于随机游走与浅层模型的方法虽然有效，但无法利用节点属性特征、无法自然泛化到未见节点，也难以适应大规模动态图，因而逐渐被能够通过堆叠层进行归纳学习（Inductive）的图神经网络取代。与书面的"嵌入"一词需要区分的是：图嵌入通常在无监督或自监督下获得，而 GNN 的表示学习则可以端到端地与下游监督任务联合优化，例如把节点嵌入用于节点分类、把整图嵌入用于图分类或图级回归。
三、消息传递机制：图神经网络的统一范式
几乎所有主流的图神经网络都可以统一抽象为一个消息传递（Message Passing）框架，其核心流程是在每一层中，每个节点收集其邻居节点的信息（消息），将这些消息进行聚合（Aggregation），再结合节点自身的特征进行更新（Update），从而得到该节点的新表示。形式上，第 k 层中节点 v 的更新可以写为：h_v^{(k)} = Update(h_v^{(k-1)}, Aggregate({h_u^{(k-1)} : u ∈ N(v)}))，其中 N(v) 表示 v 的邻居集合，Aggregate 通常采用求和（sum）、求平均（mean）、最大（max）或注意力加权的方式。通过堆叠多层，每个节点最终能"看到"其 K 跳范围内的邻居信息，感受野的大小由层数 K 决定。消息传递机制蕴含了图神经网络的几个关键性质：局部性（每个节点只从其局部邻域聚合信息，实现了天然的参数共享与归纳学习能力）、置换不变性（聚合对邻居的顺序不变，使模型不依赖节点排列）、以及可扩展性（可以泛化到训练时未见过的图与节点）。但消息传递也存在局限性，最典型的即是过平滑（Over-smoothing）问题：随着层数加深，所有节点的表示趋向一致，丧失了区分度，因此 GNN 通常层数不宜过深。此外还有过挤压（Over-squeezing，信息瓶颈）、邻居爆炸（每层邻居数指数增长）以及消息遮挡等问题。缓解过平滑的手段包括残差连接与跳跃连接、初始残差（如 APPNP、GCNII）、以及 PageRank 等个性化传播（如 PPRGo、GDC）。消息传递是理解与复现 GCN、GAT、GraphSAGE 等经典模型的基础，也是设计新 GNN 变体的出发点，深刻掌握聚合函数的选择、更新函数的构造与多层堆叠的影响，是图学习工程实践的核心技能。
四、经典图神经网络模型：GCN、GAT 与 GraphSAGE
在消息传递框架下涌现出一批奠基性的 GNN 模型。图卷积网络（GCN，Graph Convolutional Network）由 Kipf 与 Welling 提出，它将谱域图卷积近似为频谱域的一阶局部滤波，其消息更新规则为：H^{(k)} = ReLU( D̃^{-1/2} ã D̃^{-1/2} H^{(k-1)} W^{(k)} )，其中 ã = A + I 为加了自环的邻接矩阵，D̃ 为其度矩阵，这一对称归一化操作保证了对节点度的尺度不变与数值稳定，使 GCN 能高效地在一层内聚合一阶邻居信息。GCN 实现简单、效果好，是入门与基线模型的代表，但它本质上是直推式（Transductive）学习，即针对固定的图进行表示学习，难以直接泛化到训练时未见的新节点。图注意力网络（GAT，Graph Attention Network）引入了注意力机制，不再对所有邻居一视同仁地加权，而是通过注意力系数（将邻居特征与中心特征拼接后经前馈网络和 softmax 归一化得到）为不同邻居分配不同的重要性权重，从而能够自适应地建模邻居的差异化贡献，并支持多头注意力以增强表达力。GAT 天然支持归纳式学习，允许对动态或局部结构不同的图进行灵活处理。GraphSAGE（Graph SAmple and aggreGatE）则专注于大规模图的总结。其核心思想是采样（Sampling）：在每层收敛时，对每个节点的邻居进行固定数量的采样（如随机采样固定 k 个邻居），从而将消息传递的计算复杂度从全邻居降低到恒定常数，使模型能够处理拥有数十亿节点的工业级图；GraphSAGE 同时提供了均值聚合、LSTM 聚合与池化聚合等多种聚合方式，并采用归纳式学习，可以自然地对未见节点生成嵌入。除这三者外，还有 GIN（图同构网络，基于 Weisfeiler-Lehman 测试保证表达力）、GATv2、DGN 等众多变体。在工程选型中可大致遵循：小规模静态图可用 GCN，需要加权异构关注可用 GAT，超大图或动态新增节点可选 GraphSAGE，而对表达力要求较高的图分类任务可考虑 GIN。这些模型的共同点是都可直接纳入消息传递框架的统一视角来理解与实现。
五、图神经网络的任务类型与链路预测
根据预测对象的不同，图神经网络的任务主要分为三类。一是节点层面任务（Node-level），包括节点分类（如社交网络中用户的职业类别识别、引文网络中论文的主题分类）、节点回归（如用户满意度预测）与节点向量表示学习，这是最经典的 GNN 任务，常用于半监督场景——仅有部分节点有标签，模型利用图上的一致性传播标注信息。二是边层面任务（Edge-level），最典型的是链路预测（Link Prediction），即预测两个节点之间是否存在（或未来可能出现的）连接关系，广泛应用于推荐（用户-商品链接预测）、社交好友推荐、药物相互作用预测与风险金融关系发现；标准做法是取一对节点的嵌入进行内积或送入二分类器得到连接概率，并通过负采样构造训练标签。三是图层面任务（Graph-level），即对整个图进行学习，包括图分类（如分子图判定其是否有毒、图异常检测）与图回归（如分子性质预测、可通行性估计），通常通过全局池化（如求和、平均或基于注意力的 Set2Set、结构感知池化）将节点嵌入聚合成整图嵌入。链路预测与节点分类之间存在密切关联：高质量的节点嵌入通常能显著改善链路预测效果，而链路预测若要跨越多层逻辑又常常需要结合规则与外部语义知识。除了上述三类，还有更细粒度的关系三元组预测、时空图预测（如交通流量、动态社交）与图生成等方向。在具体场景中明确任务是建模第一步：不同的任务要求不同的损失函数、负样本策略与训练方式，例如节点分类常用交叉熵、链路预测常用 BPR 或二元交叉熵、图分类常用多任务交叉熵，而半监督节点分类还需要谨慎处理标签泄漏与数据划分（不可用测试信息参与训练）。
六、图与知识图谱的结合：多关系与异构建模
知识图谱（Knowledge Graph，KG）是结构化语义知识的载体，以三元组（头实体，关系，尾实体）的方式组织事实，例如（中国，首都，北京）。把图神经网络应用于知识图谱，关键在于对关系（边种类）有语义的建模，这催生了关系感知图神经网络（Relational Graph Neural Network）与知识图谱嵌入（Knowledge Graph Embedding，KGE）两类技术路线。KGE 方法（如 TransE、TransR、DistMult、RotatE、ComplEx）将实体与关系嵌入到向量或复数空间中，用打分函数度量三元组的合理性，训练目标是使正确三元组的分数高于错误三元组；TransE 把关系看作头尾实体向量之间的平移向量 h + r ≈ t，RotatE 则把关系建模为复数空间中的旋转，能够表达对称、反对称与组合关系。关系感知 GNN 的代表是 R-GCN（Relational Graph Convolutional Network），它为每种关系学习独立的消息变换矩阵，将不同关系的邻居消息分别变换后求和聚合，从而显式编码关系语义；CompGCN 则把关系作为额外的中间实体参与消息传递，减少了不同关系各自参数的膨胀。在融合路径上，一种常见做法是将 KGE 的实体/关系嵌入作为 GNN 节点与边的初始特征，配合链路预测目标联合训练，实现"结构化表示 + 深度特征"的结合。知识图谱与图嵌入的结合还支撑了图提示调优、图自监督预训练（如 GRACE、GraphMAE 的掩码重建）等更前沿的范式。这种结合的价值在于：把符号化、可解释的知识逻辑编码进可计算的向量空间，既保留了知识图谱的结构优势，又获得了深度模型的归纳与泛化能力，为大模型的知识注入与结构化检索提供了数据基础。
七、图神经网络在图检索增强（Graph-RAG）中的应用
检索增强生成（RAG）通过"检索-增强-生成"缓解大语言模型的幻觉与知识时效性问题，但传统 RAG 基于向量相似度的平面检索往往在多跳推理与关系复杂问题面前力不从心。图检索增强（Graph-based RAG）将图神经网络与知识图谱引入 RAG 体系，形成"结构化知识 + 向量检索 + 图推理"的混合范式。其工程路径通常是：首先从文档中抽取实体与关系构建知识图谱（或复用已验证的知识图谱与文档切块建立索引映射），然后用图神经网络或图嵌入模型对实体与关系学习向量表示，在收到查询时既进行文本向量的语义召回，又通过图结构的图检索（如 PageRank 社区发现、路径检索、GraphRAG 的社区检测与分层概括）召回关联实体与子图，最后把召回的结构化子图转换为自然语言上下文提示（Prompt）喂给大语言模型生成答案。GNN 在这一体系中至少扮演三个角色：一是学习统一的实体表示，使同名异构的节点对齐更准确；二是作为图检索的表示引擎，通过节点重要性加权（如 Personalized PageRank、GNN 预测的置信度）精排候选子图；三是作为多跳推理的编码器，将邻居结构与关系蕴含的推理信息转化为模型可用的特征。GraphRAG 的实践还常常配合社区检测（如 Leiden 算法）把大规模图划分为语义内聚的社区，预先为每个社区生成概括摘要，检索时先定位相关社区再生成答案，从而在保证可扩展性的同时提升多跳推理能力。图神经网络与知识图谱结合的关键工程要点包括：实体消歧与对齐、异构多源图谱融合、大规模图的采样与分布式训练、关系类型归一化、以及把图结构翻译为提示语言的合理模板设计。需要关注的是，图检索相比纯向量检索延迟更高，通常需要通过索引分层缓存、子图剪枝与图表示预计算来平衡召回质量与响应速度；同时图网络自身的过平滑与采集偏差也会影响表示质量，需要结合正确的邻居采样与归一化策略。总体而言，图神经网络为 RAG 赋予了对结构关系的建模与推理能力，是实现可解释、可多跳、可溯源的知识增强系统的关键支撑技术。
八、图神经网络的训练技巧、工具与前沿方向
要把图神经网络真正落地，训练技巧与工具链的选择同样关键。在数据划分上，节点分类通常要求"按图而非按节点"划分，训练子图与验证子图的节点不相邻，以避免信息泄漏；标签泄漏的防范尤其重要，验证集节点的表示不能被训练集节点的邻居信息污染。在负样本策略上，链路预测需要从采样中生成正负样本对，负样本既可从全局缺失连边中随机采样，也可引入难负样本与对抗采样以提升区分度。在损失与正则方面，交叉熵与 BPR 各有适用，常用 DropEdge、边丢弃与特征丢弃进行图增强，配合自监督对比学习（如 GRACE、GraphCL）在无标签数据上预训练，再在少量标签上微调，可显著缓解数据稀疏问题。在过平滑与层数的选择上，多数任务两三层的 GNN 已足够，若确需加深则应引入跳跃连接、初始残差与个性化随机游走传播，典型的如 GCNII、APPNP 与 PPRGo 等模型通过保留初始特征或扩散传播来抑制过平滑。在工程化与可扩展性上，大规模图通常需要按批次（Mini-batch）训练并结合邻居采样（如 GraphSAGE、Cluster-GCN 的图聚类分块、以及最新的大规模随机分散式采样框架），分布式训练借助 DGL、PyG（PyTorch Geometric）的多 GPU 与 CPU 采样支持，而对超大规模图还有人用 Kernel 化的图传播与预处理加速。在超参调优上，学习率、邻居采样数、隐层维度与 Dropout 比例对性能影响显著，常用的做法是结合早停与验证集选择模型。图数据的质量也直接决定效果，图净化（如去除噪声边、统一特征尺度）与连接结构的设计（如跳连接、多头邻居）往往比模型结构更能带来显著收益。常见的开源工具包括 PyTorch Geometric、Deep Graph Library（DGL）、ogb（Open Graph Benchmark 数据集与统一评测）、NetworkX（小规模图分析与可视化）与针对工业图的 GraphScope、以及面向超大规模图的分布式图计算引擎等。前沿方向则包括：基于图Transformer 的图结构建模、与语言模型联合的大规模真实图预训练（Graph Foundation Model）、把 LLM 与 GNN 结合做知识增强与图推理、动态时序图与流式图的学习、异构图与超图的建模，以及图生成用于药物与材料设计。把握好训练细节、选对工具、跟上最新研究，是把图学习能力真正转化为业务价值与检索系统效果的关键。
