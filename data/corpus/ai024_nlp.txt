# 自然语言处理（NLP）：从分词到预训练大模型的核心技术与应用全景
# 收录于 计算机检索增强语料库
一、引言：自然语言处理的定义与研究范畴
自然语言处理（Natural Language Processing，NLP）是人工智能的核心分支之一，它研究如何让计算机理解、解析、生成并与人交互使用人类语言。与处理图像、音频等相对结构化的信号不同，自然语言具有高度的歧义性、组合性、长距离依赖性与文化背景依赖性，这使得 NLP 长期被视为人工智能皇冠上最难摘取的明珠。NLP 的研究范畴极其广泛，涵盖了从底层的词法、句法、语义分析，到上层的篇章理解、情感识别、对话管理、机器翻译、文本生成与知识问答等众多任务。从技术演进的脉络来看，NLP 大致经历了三个阶段：基于规则与统计的阶段、基于神经网络表示学习的阶段，以及当前由大规模预训练模型主导的阶段。早期的规则系统依赖人工编写的语法与词典，覆盖度低且难以迁移到新领域；统计方法如 n-gram 语言模型和隐马尔可夫模型（HMM）在一定程度上缓解了稀疏性问题，但表达能力有限；深度学习尤其是 Transformer 架构的引入，使得模型能够在海量文本上自动学习通用的语义表示，极大推动了文本分类、序列标注、情感分析、信息抽取、机器翻译、文本生成等任务达到或超越人类水平。在检索增强生成（RAG）系统的落地中，NLP 能力更是贯穿始终：查询理解需要分词与意图识别，文档切片需要语义切分，召回阶段依赖语义嵌入与向量检索，重排阶段则依赖深度学习排序模型，最终答案生成依赖语言模型，可以说 NLP 是 RAG 系统中每一环的底层支撑。
二、分词与词法分析
分词是中文 NLP 的第一道工序，中文文本缺乏天然的词边界标记空格，词与词之间没有明确分隔符，因此必须先进行分词才能进行后续处理。常见的中文分词算法分为三大类：基于字符串匹配的方法（如前向最大匹配、逆向最大匹配、双向最大匹配），这类方法依赖词典，实现简单、速度快，但对未登录词（词典外的新词、人名、地名、专有名词）无能为力；基于统计的方法（如最大熵、条件随机场 CRF、基于 n-gram 频率的动态规划），通过统计相邻字符共同出现的概率来决定切分边界，能较好地发现未登录词；近年来基于神经网络的序列标注方法逐渐成为主流，即将分词视为字级别标注任务，每个字被标注为词首、词中、词尾或单字词，借助双向长短期记忆网络（BiLSTM）加 CRF 或预训练模型（如 BERT）实现。分词粒度本身也很讲究：粗粒度分词利于检索与关键词抽取，细粒度利于语义理解；面向 RAG 检索时，常采用"以词与短语共存的混合粒度"策略，既保证召回率又保证区分度。此外还有词性标注（POS Tagging），即给每个切分出来的词标注其词性（名词、动词、形容词、副词等），它是依存句法分析和语义角色标注的输入基础；命名实体识别（NER）则进一步识别文本中的专有名词，包括人名、地名、组织机构、时间、金额、比例、产品名等类别。NLP 分词工具与库非常丰富，国内常见的有 jieba、HanLP、LTP、THULAC 与结巴分词衍生工具，国际上则有 spaCy、Stanza、Stanford CoreNLP 等。在现代大模型时代，基于子词（Subword）的分词方法（如 BPE、WordPiece、Unigram）已经成为预训练模型的标准输入范式，它通过合并高频字节对或字符片断构建词表，兼顾了词汇覆盖与词表规模的平衡，是理解大模型输入表示的关键概念。
三、词向量与分布式表示
要让计算机处理自然语言，首先必须将离散的词汇表示成计算机可运算的向量，这就是词向量的核心使命。最早的表示方法是独热编码（One-Hot），每一个词对应一个维度为词表大小的稀疏向量，词的维度上置一、其余置零。独热编码的问题非常明显：维度爆炸导致计算开销巨大，且任意两个词之间不存在任何语义相似度度量，无法体现"猫"与"狗"都属动物的关联。分布式表示（Distributed Representation）的思想由此而生：即用低维稠密的实数向量来刻画一个词，向量的每一个维度并不对应明确的语义单元，而是通过在不同上下文中共同出现的关系共同刻画该词的语义。经典方法包括 Word2Vec、GloVe 与 FastText。Word2Vec 由 Mikolov 等人提出，包含连续词袋模型（CBOW）与跳字模型（Skip-gram）两种训练范式：CBOW 用上下文词预测中心词，Skip-gram 用中心词预测上下文词，两者都通过神经网络在语料上训练，最终学习到的词向量能够体现词之间的类比关系（如"国王减去男人加上女人约等于女王"）。GloVe 利用全局共现矩阵的统计信息构造目标函数，兼顾了局部窗口与全局统计；FastText 则在词向量基础上加入了子词（字符 n-gram）信息，能较好地处理未登录词与形态丰富的语言。词向量是下游模型（文本分类、情感分析、NER、机器翻译）的输入基础，但也存在一词多义（一词形对应多义义）无法区分的问题，因为每个词只有一个固定的向量。上下文相关表示（Contextualized Embedding）应运而生：ELMo 通过双向语言模型为同一个词在不同上下文输出不同的表示；而 BERT 等预训练模型则进一步把词向量进化为"字或子词 + 位置 + 段"多层编码后的动态向量，成为现代 NLP 事实上的标准表示。在 RAG 系统里，句向量与文本嵌入（Sentence / Document Embedding）就是在词向量思想上的扩展，它将整段文本映射为固定的稠密向量，以便在高维空间中进行语义相似度的余弦计算与向量检索，代表模型包括 BGE、GTE、E5、M3E、text-embedding 系列等，其训练往往采用对比学习与难负样本采样策略。
四、语言模型及其演进
语言模型（Language Model，LM）是给一句话或一段文本赋予概率的模型，它量化了"什么样的词序列更像自然语言"。传统统计语言模型使用马尔可夫假设，用 n-gram 计算 P(w_t | w_{t-1},...,w_{t-n+1})，即预测下一个词时只依赖前 n-1 个词，频率估计配合平滑技巧（如加一平滑、Kneser-Ney 平滑）缓解稀疏问题，但 n 无法取太大，长距离依赖会被截断。神经网络语言模型（NNLM、RNN-based LM）通过学习词的分布式表示并用循环结构建模任意长度的历史，显著提高了语言建模能力；LSTM 语言模型曾在很长一段时间内是文本生成与机器翻译的核心引擎。而 GPT 系列与 BERT 等预训练语言模型的出现，将语言建模推向新高度：GPT 采用自回归（从左到右逐词预测）方式预训练，擅长生成；BERT 采用掩码语言模型（Masked Language Modeling，MLM）+ 下一句预测的方式预训练，擅长理解。预训练（Pre-training）就是先在海量无标注语料上自监督学习通用语言知识，再通过微调（Fine-tuning）适配下游任务，这一"预训练 + 微调"范式彻底改变了 NLP 的研发方式，使得只需很少的标注数据即可获得强大的模型能力。在大模型时代，语言模型进一步升级为大语言模型（LLM，如 GPT-4、Claude、LLaMA、Qwen、DeepSeek、GLM），参数规模从亿级到千亿、万亿级，配合指令微调（Instruction Tuning）、人类反馈强化学习（RLHF）、监督微调（SFT）等手段获得强大的指令遵循能力、工具调用能力与少样本乃至零样本学习能力。对 RAG 系统而言，大语言模型担当检索结果的组织与答案生成的"大脑"，其上下文窗口、生成长度、指令遵从度直接决定了 RAG 的产品体验，同时语言模型的困惑度（Perplexity，PPL）仍是衡量语言建模质量的常用指标。
五、序列标注：一个统一的任务范式
自然语言处理中大量任务可以归结为序列标注问题，即为输入序列中的每一个元素（字或词）打上一个标签。典型的序列标注任务包括词性标注、命名实体识别、中文分词（字级标注）、语义角色标注、槽位填充（Slot Filling）、事件的触发词与论元标注等。序列标注的经典方法包括隐马尔可夫模型（HMM）、最大熵马尔可夫模型（MEMM）与条件随机场（CRF）。其中 CRF 是一种判别式概率图模型，它考虑标签之间的转移约束与特征函数，能够输出全局最优的标签序列，长期是序列标注的黄金基线。在深度学习时代，主流方案是 BiLSTM-CRF 或 BERT + 线性层 + CRF：双向 LSTM 或预训练编码器提取字/词级别的上下文表示，线性层计算每个位置的标签分数，CRF 层则通过维特比（Viterbi）算法解码出满足标签转移约束的最优路径。以命名实体识别为例，模型在微调阶段学习识别"某组织、某产品、某病名、某金融实体"等类别，广泛应用于信息抽取、知识图谱构建、医疗文本处理与金融风控。序列标注在 RAG 中的价值体现在文档语义的结构化理解上：通过抽取式问答（抽取答案片段）、关键词识别、事件抽取，可显著增强对文档的精细理解，帮助构建更高质量的索引结构。值得注意的是，Transformer 编码器无法天然感知位置，因此需要注入位置编码，而序列标注模型的输出后处理也非常关键，常用 BIO 标注体系（B-实体开始、I-实体中间、O-非实体）来刻画边界信息。
六、情感分析与文本分类
文本分类是自然语言处理中被应用最广泛的任务之一，它旨在判断一段文本属于预定义的类别集合中的哪一类；从垃圾邮件识别、新闻主题分类，到意图分类、风险分级，再到情感分析，本质都是文本分类或其变体。情感分析（Sentiment Analysis）是文本分类在情感维度的专门应用，目标是从文本中识别观点、态度与情绪倾向，通常划分为正面、负面、中性三类（细粒度情感分析则进一步区分喜好程度与多个情感维度，如喜怒哀乐）、以及面向实体的细粒度情感（针对某个具体实体或属性的情感，即方面情感分析 ABSA）。经典技术路线也经历了从词典法（基于情感词典统计情感词）到传统机器学习（朴素贝叶斯、支持向量机结合 TF-IDF 特征）再到深度学习的演进。深度学习方法中，基于 CNN 的模型擅长捕捉局部 n-gram 特征，基于 RNN/LSTM 的模型擅长捕捉长距离时序依赖，而基于注意力机制与预训练模型的方案（BERT 文本分类、提示学习 Prompt 分类）当前表现最优，尤其在少样本与多语场景下稳定可靠。文本分类的评估指标通常包括准确率（Accuracy）、精确率（Precision）、召回率（Recall）与 F1 值，对于类别不平衡问题还常引入 PR 曲线与 ROC-AUC。在 RAG 落地中，文本分类能力被广泛用于查询理解与路由：判断用户查询是检索型还是生成型，将其路由到向量检索、倒排检索、SQL 查询或直接语言模型生成等不同处理链路，分类模型的分层与决策边界直接关系到系统的整体准确率与延迟。
七、实体识别、机器翻译与文本生成
命名实体识别在信息抽取中举足轻重，它从非结构化文本中识别出具有特定含义的实体及类别，是构建知识图谱、问答系统与情报分析的重要基础；在金融文本中抽取公司名、证券代码、金额，在医疗文本中抽取药品与疾病名，在对话系统中抽取意图与槽位，皆是实体识别的典型应用。机器翻译（Machine Translation）旨在将文本从一种语言自动翻译为另一种语言，其技术从早期的统计机器翻译（SMT，基于短语对齐与语言模型）演化为神经机器翻译（NMT，Sequence-to-Sequence 模型 + 注意力机制），再到当前大规模多语预训练与大型语言模型的上下文翻译范式。Transformer 的编码器-解码器结构在翻译中表现优异，而现代大语言模型凭借强大的多语能力与指令遵循能力，可以在少样本提示翻译、语体控制翻译、术语一致性约束等场景提供更灵活的解决方案。文本生成（Text Generation）则涵盖了摘要生成（抽象式与抽取式）、对话回复、故事创作、代码生成、文案营销等内容生产任务，从早期的 n-gram 与模板生成，到 LSTM 语言模型的逐词采样，再到预训练模型与自回归生成策略（贪心搜索、束搜索 Beam Search、温度采样、Top-k、Top-p 核采样），生成质量和可控性不断跃升。机器翻译与文本生成都高度依赖解码策略与概率分布的抽样，过热或过冷的采样都会导致重复或低多样性，因此解码参数的调优是工程中的关键细节。在 RAG 语境下，文本生成是答案合成的最后一公里，模型需要忠实于检索到的证据片段，避免幻觉，因此常结合引用标注（Citation）、忠实度提示（如"仅依据给定文档作答"）与可控生成策略来提升答案的可信度与可追溯性。
八、预训练模型及其 NLP 应用范式
预训练模型（Pre-trained Model）是当代 NLP 的技术基石，其核心范式是在大规模无标注语料上以自监督方式学习通用表示，然后通过微调或提示适配下游任务。代表性模型谱系包括：以 BERT、RoBERTa、ALBERT 为代表的编码器模型，擅长分类、序列标注与检索排序；以 GPT、LLaMA、Qwen、DeepSeek 为代表的自回归解码器模型，擅长文本生成与对话；以 T5、BART 为代表的编码器-解码器模型，兼顾理解与生成。在中国开源生态中，Qwen、DeepSeek、GLM、InternLM 等模型发展迅猛，支持长上下文、Tool Use 与多模态。预训练模型的下游应用范式经历了从全参数微调（Fine-tuning）、参数高效微调（PEFT，如 LoRA、Adapter、Prefix-tuning）到提示学习与上下文学习（In-Context Learning）的转变，LoRA 通过低秩分解的旁路矩阵实现极小的可训练参数量，成为大模型领域应用最广的高效适配技术。在 RAG 系统中，预训练模型扮演多个角色：嵌入模型（Embedding Model）负责把查询与文档编码为向量用于召回；重排模型（Reranker，如 bge-reranker、cross-encoder）负责对召回的候选做精细的相关性打分排序；生成模型（LLM）负责最终答案的组织与生成，而嵌入与重排模型的训练质量直接决定了 RAG 的检索精度。此外，针对特定领域（医疗、法律、金融）的 RAG 还常采用领域继续预训练（Domain Continual Pre-training）以增强术语理解。总体而言，预训练模型的发展让 NLP 从"技术驱动的特征工程"转向"数据驱动的表示学习"，也把检索、抽取、生成等能力统一到了同一个表示空间，为构建跨任务的统一智能系统铺平了道路。
九、NLP 任务的常用数据集与评估方法
评估是 NLP 研发闭环中不可或缺的一环，任何模型在部署前都必须先在标准数据集上验证其能力。文本分类与情感分析的常用基准包括中文的 THUCNews、ChnSentiCorp 以及英文的 AG-News、IMDB、Yelp 等；命名实体识别常用数据集有英文的 CoNLL-2003（含人名、地名、组织、其他四类）、中文的 MSRA、OntoNotes，以及面向医疗、金融等垂直领域构建的工业标注集；机器翻译的常用评估数据集包括 WMT 系列的公开测试集与 BLEU、ROUGE、METEOR 等自动评估指标。BLEU 通过计算候选译文与参考译文在 n-gram 级别上的重合度来打分，ROUGE 则侧重于召回程度，常用于摘要评估，而文本生成任务除了这些基于词元重合的指标外，越来越重视基于大型语言模型的人工与自动评测（如 GPT 打分的连贯性、相关性、忠实度）。在落地工程中，还需要区分离线评估与在线评估：离线评估基于留出集或人工抽检，在线评估通过 A/B 实验观察业务指标（如点击率、转化率、满意度）。此外，模型鲁棒性与公平性问题日益受到重视，例如分析对抗样本扰动对模型的影、评测多语言与方言场景的表现。一个完整的 NLP 项目通常包含数据清洗与去重、标注规范制定、模型训练与超参调优（学习率、批大小、正则）、基线对比、误差分析与增量迭代等环节，其间还要注意训练与测试数据的污染防控，避免评测失真。理解这些评估体系，能够帮助研发者在面对业务需求时，科学地设计与验证 NLP 方案，而不是仅凭直觉或单一指标下结论。
十、NLP 与检索增强的结合要点
在检索增强生成（RAG）系统中，NLP 能力贯穿数据准备、检索、重排与生成四个阶段，理解两者的结合要点对构建实用系统至关重要。在数据准备阶段，需要运用文档解析、段落切分、语义去重与摘要生成等技术，把非结构化文本整理成适合检索的片段，并利用分词与命名实体识别抽取关键词与实体，构建倒排索引与向量索引的补充字段。在查询理解阶段，NLP 帮助识别用户的真实意图：通过意图分类判断查询是事实型、多跳型还是观点型，通过查询改写（Query Rewrite）与同义词扩展提升召回率，通过实体链接把文本中的实体映射到知识库。在召回阶段，语义嵌入是核心，常用的做法是以预训练模型为骨干微调出查询向量与文档向量，通过余弦相似度在向量库中检索 Top-K。在重排阶段，通常引入基于交叉编码器（Cross-Encoder）的重排模型，对召回候选做精细的相关性打分，弥补双塔式的速度优势所付出的精度损失。在生成阶段，需要设计高质量的提示词把检索到的证据片段与原始问题组织起来，并对大语言模型的输出进行事实性校验、引用标注与去幻觉处理。值得强调的是，领域适配是 RAG 落地的难点：医疗、法律、金融等垂直领域的术语繁多、语义粒度差异大，往往需要领域继续预训练、领域数据集的训练、以及针对性的评测体系。总体而言，NLP 为 RAG 提供了从底层表示、任务建模到系统评估的完整工具链，只有把扎实的 NLP 基础与检索工程深度结合，才能构建出准确、可解释、可运营的知识增强问答与对话系统。
