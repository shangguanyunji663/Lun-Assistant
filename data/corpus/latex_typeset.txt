# LaTeX 论文排版技术与实务
# 郑远航 罗一鸣 计算机科学 2024
一、引言：LaTeX 为何适合作论文排
学术论文对排版质量要求极高，尤其是数学公式、交叉引用、表格与参考文献的统一编排，传统所见即所得工具往往难以胜任。LaTeX 以其"所见即所得"取代为"所编即所得"的理念，通过源码描述版面，实现了公式专业、引用自动、排版一致性强的优点，因而在理工科期刊投稿、会议论文与学位论文写作中被广泛采用。所谓"所编即所得"，是指作者书写的是描述文本结构与样式的"源代码"，再由编译程序得到版式划一的输出；这种"内容与表现分离"的做法，让同一份源稿可以针对不同期刊的格式要求切换版式，而不必重排内容。
LaTeX 的核心在于用纯文本控制版面，把排版逻辑与内容分离，配合庞大的宏包生态，几乎能满足一切学术排版需求。数学公式能以接近出版质量的精度呈现，图表自动编号与浮动、交叉引用自动维护、参考文献统一管理，这些特性共同构成了 LaTeX 在严肃学术出版中的不可替代性。本文将从基础与工具链、文档结构、数学公式、表格插图、参考文献、模板使用、交叉引用与常见问题等方面展开系统介绍，帮助读者从入门到熟练，建立完整的 LaTeX 排版能力。
二、LaTeX 基础与编辑器选型
LaTeX 是建立在 TeX 之上的排版系统，通过编译器把以\.tex 结尾的源文件翻译为 PDF 文档。入门者不必深究底层编译机制，而是应熟悉：源文件的编写方式、常用宏包（package）的加载、以及编译工具链（如 pdflatex、xelatex、lualatex 等）的选择。
编辑器选型上，云端协作优先推荐 Overleaf：无需本地安装、天然支持多人协同与实时编译，且内置大量期刊与学位论文模板，对新手尤为友好。本地进阶则可选用 TeXstudio、VS Code 配合 LaTeX Workshop 或 TeXworks 等：TeXstudio 集成度高、可折叠章节与快速预览公式，VS Code 以其生态灵活与 Git 集成见长。选择哪种并不关键，关键是把"源码—编译—预览"的循环打磨顺畅，并养成及时编译检查的习惯。
三、文档结构与章节组织
一个规范的 LaTeX 文档从"导言区"与"正文区"两部分构成。导言区位于前导段之间，负责声明文档类型（如 report、article、book；中文与学位论文常用 ctex 文档类）、加载宏包、设置页面样式与自定义命令；正文区则在 begin 与 end 之间，撰写实际内容。
章节组织依靠 documentclass 提供的结构化命令：part、chapter、section、subsection 等按层级划分，LaTeX 会自动生成章节编号，并通过目录或交叉引用把结构串联起来。合理的章节层级不仅让源码清晰，也直接影响目录自动生成与编号引用的准确性。建议一开始就选定文档类与中文字体方案（如 xelatex 配合 ctex 宏包），避免后期大规模改动目录与编号机制。
在组织长篇幅论文时，还可采用"主从式"结构，即把一个文档拆分为主文件与若干子文件（通过 input 或 include 引入子章节），既便于团队分章协作，也利于按章节单独编译排查错误、实现"每次只编译修改过的部分"以加快反馈。中文字体与编码（UTF-8）的正确配置是中文 LaTeX 排版的前提，ctex 宏包与 xelatex 的组合是目前最稳妥的中文方案，能同时满足字体、连字与中英文混排的规范要求。
四、数学公式的排版
LaTeX 最负盛名的能力之一就是数学公式排版，它能产出与印刷质量相当的专业公式。
行内公式与行间（display）公式是基本载体：行内公式夹在文本中，行间公式单独成行并自动编号、可被交叉引用。公式中涉及的上下标、分数、根式、求和极限、矩阵、多行对齐等结构，均有对应的环境（如 align、gather、cases）与命令（\frac、\sum、\left( \right) 等），符号库覆盖几乎所有数学运算。
工程经验上，使用"多行对齐"环境时需注意 &、\\ 的排列逻辑以控制对齐点；引用公式时利用 eqref 或引用机制而非手打编号，才能保证增删公式后编号不乱。对中文字符与数学符号并存的情况，配合 ctex 与 amsmath 等宏包可保持排版协调。公式质量体现了论文的技术严谨度，值得反复校验。
对复杂推导，还可结合注释与分段排版的方法把长公式拆解为若干逻辑步骤，既提升可读性，也便于审稿与复现。当公式数量庞大时，利用宏包提供的自动编号与定理环境可以系统管理编号资源，避免人工维护的疏漏。
五、表格与插图的制作
表格与插图是承载数据的核心载体，其排版同样由 LaTeX 统一处理。
表格常采用 tabular 或更灵活的 tabularx、longtable 等环境，通过"列格式对齐"（l、c、r、p 等）、表头分隔与合并单元格（\multicolumn、\multirow）构建数据表，表题用相关的 caption 宏包与 \caption 命令自动编号。处理长表格跨页时，longtable 可自动分页并重复表头。
插入图片则通过 graphicx 宏包，用 figure 浮动体包裹 \includegraphics，并指定图片路径、宽度与对齐方式。浮动体机制让 LaTeX 自动把图表放到合适位置，避免打断正文阅读；同时对图表实现"编号—题注—标签"的一体化，为交叉引用提供基础。图片的格式（PDF、PNG、基于矢量源的 PDF/EPS）选择会影响清晰度，矢量图在印刷时质量最佳。
排版图表时还有几个值得留意的细节：其一，浮动体位置（htbp 参数）与"强制原位"需平衡，避免图表涌到不应出现的章节；其二，表格超出页面宽度时应使用横向排列或缩小字号、列宽处理，而不是简单缩放破坏阅读；其三，中文图表题注与正文的字体字号需与模板保持一致。表格与图表的专业呈现，直接反映论文的整体质感，是审稿人与读者的第一直观印象所在。
六、参考文献与 BibTeX/BibLaTeX 管理
参考文献是论文排版的难点之一，LaTeX 提供了强大的自动文献管理方案。
最经典的是 BibTeX 配合 bibliography 机制：把文献按条目写入 .bib 文件，在正文用 \cite 命令标注引用键，编译后由 BibTeX 依据所选择的样式文件自动生成参考文献表，并排版为顺序编号或著者-出版年等不同格式。更新的 BibLaTeX 在灵活性、跨语言与本地化支持上更进一步，配合 biber 编译后端可处理更复杂的著录。
使用这一机制，作者只需维护一个结构化的 .bib 数据库，即可在多种引用样式间切换，并保证文中引用与文末文献表的一致性。与 EndNote、Zotero 等文献管理工具导出 .bib 文件配合，能将文献管理的成本降到最低。要避免常见的"引用键重复""条目字段缺失""样式不符"等问题，务必在编译后核对生成的文献表。若采用著者-出版年样式，BibLaTeX 与 biber 的支持更完善，跨语言与本地化也能更从容地处理中文文献。
七、模板的使用与学位论文/期刊模板
几乎所有的期刊供稿与学位论文都有官方 LaTeX 模板，正确使用模板能免去大量版面细节的重复劳动。
使用模板的首要原则是"尊重官方结构"：在期刊提供的模板源码上填充内容，而不要擅自改动其文档类、宏包与样式定义，以免破坏审稿或印刷要求。学位论文模板通常由学校提供或由社区维护，内含中文学位格式、图表题注体例、目录与会章格式、参考文献样式等全套定义，直接在其上写作是最省力且最稳妥的路径。
模板使用中还应注意版本一致性与编译链路的匹配：某些模板要求特定编译器（如 xelatex）与特定宏包版本，换编辑器或断网编译时若出现文件缺失，需要先解决宏包安装问题。除此之外，把模板的编译配置（编译器、编解码选项）固定在工程的最上层，是保证任意机器都能稳定复现的关键。
与模板配套的还有"版本管理与协作"：推荐把 .tex 工程纳入版本控制（如 Git），每次重要改动留下提交记录，既便于回溯也方便多人协同；使用 Overleaf 时则可利用其内置的版本回退与标注功能。规范的工程组织，让模板的价值不止于"一次性产出论文"，更成为可持续迭代与复用的可靠底座。
八、编译流程与常见错误排查
编译是 LaTeX 工作流中容易让人受挫的环节，掌握常见的错误类别与排查方法至关重要。
LaTeX 编译常见的错误大致分为几类：语法错误（如命令缺失、花括号不配对、'&' 使用不当）、宏包缺失或版本不兼容、字符编码与字体问题（尤其中文在 xelatex 下的字体配置）、以及编译流程问题（引用未得到第二次编译、标签未解决、BibTeX 步骤遗漏）。
实用的排查习惯包括：其一，逐条阅读日志中的首个错误信息，从出现错误的源头修正而非顾后结节；其二，善用"多遍编译"——交叉引用与文献表常需连续编译几次才能最终就绪；其三，对中文字体与编码统一使用 xelatex 并显式加载 ctex 宏包；其四，用最小化方法隔离问题（注释掉无关段落定位出错位置）。掌握这些方法，绝大多数编译故障都能在短时间内得到解决。
对于调试、输出与编译，还要强调"日志即答案"的理念：LaTeX 的 .log 文件里通常详尽记录了每一次命令执行与错误上下文，与其反复猜测，不如顺着日志从最初报错的地方向下追查，很多看似复杂的"连环报错"其实源于同一个根源问题。一旦解决了根因，后续一系列连锁错误往往随之消失。若遇到宏包冲突或字体缺失这类环境问题，先检查 TeX 发行版是否完整、宏包版本是否与模板兼容，再寻找社区解决方案，通常比从零重排更高效。
九、排版细节：页面、字号、间距与对齐
LaTeX 的排版美感很大程度上来自对页面细节的精细控制，而这恰恰是许多人忽略的部分。
页面参数（纸张、页边距、页眉页脚）通过 geometry 等宏包设置；行距、段间距、字距与断词由 setspace、microtype 等宏包调节；页面内的各类对齐、留白、公式与图表的间距也各有规范。这些细节看似琐碎，却决定了整篇论文的观感是否专业、印刷是否达标。
实践中有几个容易踩坑的细节：其一是中文标点与引号的处理（中文引号 "" 与直引号不可混用）；其二是行距对图表与公式的继承，修改正文行距时须检查浮动体与脚注是否跟随；其三是过满或过空的"断版"处理，可通过调整浮动位置、禁止字行与允许自动断词来优化页面利用率。把排版细节打磨到位，论文才能从"能看"进阶为"精致"。一以贯之的原则是"先在模板/样式层定规范，再让内容自动适配"——把页面、字号、间距等一次性在导言区配置妥当，正文只需负责内容本身，版面自然整齐统一。
十、与 AI 辅助写作的协同
在论文辅助平台语境下，LaTeX 排版的自动化与 AI 辅助可以良好结合。
一方面，许多平台可将论文内容输出为结构化或直接生成 .tex 源码，用户只需选定模板与编译器即可产出专业版式的 PDF，大幅降低排版门槛；另一方面，面对 LaTeX 语法错误、公式命令、宏包选型与构图技巧，AI 可作为即时咨询助手，帮助新手答疑、排查错误并优化版面。
但 AI 生成的 LaTeX 代码更需谨慎：生成的宏包加载与命令往往存在版本差异或冗余，若直接用于严格模板，可能引入编译问题或破坏格式约定。稳妥的实践是把 AI 用于"局部生成与辅助排错"，而把模板惯例与编译控制交由作者把握，在编译验证通过后再正式采用。对待 AI 产出的代码，原则与对待任何引入的外部代码一致——"看懂、验证、再合入"，切勿图省事而盲目信任。
十一、交叉引用、目录与超链接
一篇合格的学位论文或长文，离不开流畅的"章节互见、图表互引"，而这正是 LaTeX 的长项。
交叉引用建立在"标签—引用"机制上：先在章节、公式、图表、段落处定义标签（label），再在正文通过 ref、eqref、pageref 等命令引用，编译时 LaTeX 会自动把标签解析为正确的编号与页码。这样做的巨大好处是，无论增删章节还是调整顺序，所有引用都能在重新编译后自动同步，不必人工维护编号。
目录与图表目录则由 tableofcontents、listoffigures、listoftables 命令自动生成，配合 tocdepth 控制显示层级；配合 hyperref 宏包，目录与文内引用还能生成可点击的 PDF 超链接，让电子版阅读在章节间自由跳转。需要提醒的是，交叉引用与目录的准确性依赖于"多次编译"——首次编译建立标签，再次编译解析编号，习惯上先编译两次、最后再编译一次以得到最终结果，避免因标签未解析而出现"??"乱码。
在涉及大量图表与公式的论文中，良好的标签命名规范本身就是一种工程素养：建议采用"前缀+含义"的清晰命名（如图表用 fig:xxx、表用 tab:xxx、公式用 eq:xxx），既便于维护，也减少重名冲突。配合 hyperref 的快速跳转功能与 pdf 书签，读者在阅读电子版时可沿目录和引用逐级导航，显著提升长文档的可读性。
十二、自定义命令与宏包生态的合理运用
随着论文复杂度的提升，善用自定义命令与宏包能显著降低重复劳动、维持版式统一。
自定义命令（如 newcommand、renewcommand）可将反复出现的表达式、术语或版式片段封装为简短命令，既减少拼写负担，也保证全文一致性。例如把一个长公式或固定的图注写法抽象成命令，改一处即可全篇同步。宏包则是 LaTeX 扩展能力的载体：amsmath 强化数学排版、graphicx 处理插图、booktabs 美化表格、titlesec 微调标题、fancyhdr 定制页眉页脚，等等。选择宏包时应"按需加载、避免冗余"，同类冲突的宏包往往导致选项冲突，需要学会阅读文档与搜索解决方案。
在模板语境下尤其要克制自定义：模板已定义的样式不应随意覆盖，新增命令也应避免与模板内置命令重名。在"够用、统一、可维护"的原则下运用自定义能力，既能享受高效，又不会给自己埋下排版的隐患。
十三、结语
LaTeX 以"内容与样式分离"的设计哲学，为学术论文提供了专业、稳定、可复现的排版方案，从文档结构、数学公式到表格插图与参考文献，几乎覆盖论文写作的全部排版需求。掌握基础工具链、善用官方模板、养成多遍编译与规范排错的习惯，并将 AI 辅助定位为"提升效率的助手"而非"替代排版纪律"的捷径，就能让 LaTeX 成为助力科研写作的可靠工具，使论文在内容之外同样以周到的排版呈现其专业价值。
